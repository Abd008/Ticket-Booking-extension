# 🌐 QT — Quick Tatkal Extension (v2)

A Chrome extension designed to assist IRCTC Tatkal booking using smart DOM automation and Angular-aware interaction handling.

---

## ⚡ Features

* 🚄 Auto train selection
* 🪑 Class selection (Sleeper / AC)
* 📅 Date selection
* 🎯 Smart "Book Now" detection
* ⚡ Angular-safe click handling (fixes normal extension failures)
* 🔁 Retry + fallback system

---

## 🧠 Tech Stack

* JavaScript (Chrome Extension API)
* DOM Automation
* MutationObserver
* Event Simulation

---

## 🚀 How to Use

1. Load extension in Chrome (Developer Mode)
2. Open IRCTC website
3. Login manually
4. Open extension popup
5. Enter details and click **Start**

---

## ⚠️ Disclaimer

This tool does NOT bypass CAPTCHA or IRCTC security systems.
It only assists with faster interaction.
